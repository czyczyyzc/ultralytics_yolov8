## 原图表现和局限

在同一批原图上，328 贴图、50% Add-on P2 的 P/R/FP/mAP50 为 **49.30%/84.42%/1,081/79.02%**；40 视频不换贴图 Add-on P2 为 **51.73%/82.81%/962/78.51%**。贴图训练的额外误检也出现在未修改的真实负样本：前者 716 FP，后者 664 FP。

两个视频差异较大：328 贴图、50% Add-on P2 在合成 Video00004 的 P/R/FP/mAP50 为 **36.29%/97.77%/769/90.53%**；在合成 Video00009 为 **70.44%/80.43%/269/79.08%**。因此不能只凭合并 Recall 判断可直接部署的阈值。完整分视频与原图表见 [REPORT.md](REPORT.md)。

328 张候选贴图已经用于训练，这不是未见机型测试。Video00009 参与过模型选权重，合并集也不是独立盲测。合成后的 bbox 随透明轮廓变化，小目标 IoU 对像素级框变化敏感。当前仅是服务器 FP32 `.pt` 精度，尚不能代表 RKNN INT8 精度或板端 FPS。
