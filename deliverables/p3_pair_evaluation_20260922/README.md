## 评测范围与参数

- 五组均为纯 P3 检测器，使用训练已选定的 `best.pt`；没有 P2、Tracker 或 RKNN INT8 量化。
- 输入 `960x544`（宽 x 高），FP32；NMS IoU=0.45，匹配 IoU=0.50，max_det=100。
- 表中 Precision、Recall、TP、FP、FN 和小目标 Recall 使用 `conf=0.03`。
- mAP 从置信度下限 0.001 的预测计算，并非只用 conf=0.03 以上的框。
- Video00004：既有测试集，2,359 帧、448 个 GT。
- Video00009：选权重用的验证子集，1,421 帧、797 个 GT；不是原始视频全帧。64 张合成放大验证图不计入本表。
- 合并共 3,780 帧、1,245 个 GT。合并 P/R 按总 TP/FP/FN 重算，合并 mAP 按全部预测重新排序计算，不取两个视频的 mAP 平均值。
- Video00009 参与过选权重，所以合并结果是“测试集 + 验证集”，不能称为独立测试结果。本轮没有重新选权重、调阈值或训练。
- “50% / 15%”表示对符合缓存条件的正样本尝试换贴图的概率，不是负样本比例，也不是全部图片的实际替换比例。不换贴图组保留其他既有增强。

## 结论

本次合并结果中，不换贴图的 40 视频 P3 取得最高 Precision 和 mAP50，Recall 与 328 贴图、50% 替换版相同。相比后者，TP 均为 769，但 FP 从 606 降到 462，减少 144 个（23.76%）。两组总 TP 相同不代表检出的是完全相同的帧或目标。

相比旧 28 视频 P3，不换贴图版的合并 Recall 提升 2.33 个百分点，mAP50 提升 5.05 个百分点，TP 增加 29，FP 增加 3。但 Video00004 单独看，FP 从 249 增到 297，Precision 从 57.51% 降到 53.59%，所以不能说每个视频、每项指标都提升。

15% 替换版相对不换贴图版多 2 个 TP，但多 187 个 FP；并未取得更好的整体取舍。当前结果不支持“换贴图必然改善纯 P3”。这不能外推为 P3+P2 的结论，也不能据此否定贴图在未见机型上的潜在价值。未做多随机种子复验、全新独立视频验证或本批模型的板端量化验证；当前部署模型未更换。
