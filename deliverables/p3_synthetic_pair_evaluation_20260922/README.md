## 结论与限制

在本次完整合成集上，40 视频 + 328 贴图、50%替换版的 Recall 和 mAP50 最高。与同为 40 视频的不换贴图版相比，Recall 高 5.94 个百分点、mAP50 高 6.62 个百分点，但 FP 多 97 个，Precision 低 1.93 个百分点。差值按未四舍五入值计算。

只看 981 个真正换机型的配对帧，50% 全贴图版比不换贴图版多检出 73 个目标，FP 同为 121；Recall 高 7.44 个百分点，mAP50 高 8.39 个百分点。说明贴图训练对本次同类合成外观的适应能力有帮助。15%版比50%版在此子集仅多1个TP，却多26个FP，mAP也较低，并无全面优势。

50% 全贴图版相对不换贴图版的额外误检主要来自未改变的真实负样本：FP 为 406 对 303，多 103 个；保留原图的正样本 FP 为 51 对 57，少 6 个，合计净增 97。成功替换子集的 FP 均为 121。这不是合成流程改坏了负样本图片，而是两种训练版本对同一批原始背景的误检能力不同。

这不推翻真实原图上的取舍：40 视频不换贴图版在原图合并集的 mAP50 仍最高（65.51%，50% 全贴图版为 63.64%）。所有五组原图指标已精确复现之前的报告。

328 张候选贴图已用于此前训练；这是已见贴图、相同合成流程下的外观测试，不是未见机型泛化证明。Video00009 参与过选权重，合并集也不是独立盲测。贴图轮廓会改变 bbox，而像素级框变化对小目标 IoU 很敏感；合成结果不能完全替代真实新机型视频。未做多随机种子显著性验证，也未验证本轮模型的 RKNN INT8 精度或板端速度。
